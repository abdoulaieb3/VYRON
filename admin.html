Ajouter un produit, en 5 étapes :
  1. Mets la ou les photos dans le dossier assets/products/ (idéal : 1000×1250 px).
  2. Clique ＋ Nouveau produit, remplis les champs (nom, prix, tailles, photos, descriptions FR + AR).
  3. Pour la photo, écris juste le nom du fichier (ex : mon-tee-1.jpg) — ou colle une URL complète.
  4. Clique ⬇ Télécharger products-data.js, puis remplace le fichier products-data.js à la racine du site.
  5. Ré-uploade le dossier chez ton hébergeur (Netlify : glisser-déposer). C'est en ligne.
Tes modifications sont gardées automatiquement dans ce navigateur (brouillon local) tant que tu n'as pas téléchargé. Le stock se change directement dans la liste ci-dessous avec l'interrupteur En stock.
